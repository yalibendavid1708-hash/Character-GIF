# GIF Studio – הדמות שלך

1. העלה את כל הקבצים שבתיקייה הזו למאגר GitHub.
2. ב-GitHub: Settings → Pages.
3. תחת Build and deployment בחר Deploy from a branch.
4. בחר `main` ואת `/ (root)` ולחץ Save.
5. פתח את כתובת GitHub Pages שתופיע.

האתר עובד בדפדפן בטלפון ובמחשב. ייצוא GIF דורש אינטרנט כדי לטעון gif.js מה-CDN.

הערה: הידיים באנימציות המטבע והאגרוף הן איורים שנוצרים בקוד, מכיוון שבתמונת המקור אין ידיים גלויות.
